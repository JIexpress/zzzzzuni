# TASK-A-CONT-01 —— 内容管线起步：第一套环境贴图

> 背景：接管体检发现 `Art/Textures` **0 张位图**，10 个材质全是纯色 URP/Lit——
> 这是「像不像游戏」的第一权重，也是路线图 D 类「贴图管线实战」的第一刀。

## 一、目标

1. 建立**可复现的贴图资产**（程序化生成，不依赖外部素材/版权）。
2. 把环境材质从「纯色」升级为「贴图 albedo」，并统一导入设置。
3. 加一条**内容管线守卫**：材质必须挂图、贴图必须 mipmap+Repeat+sRGB、底色必须白。
4. 用像素指标证明「细节真的变多了」，而不是只靠肉眼。

## 二、实施记录

**贴图（6 张，256×256，程序化 value-noise，可平铺）**

| 贴图 | 用途 | 生成方式 |
|---|---|---|
| `T_ENV_Grass` | 地面 | 3 层噪声 + 高频草叶扰动 |
| `T_ENV_Road` | 路面 | 低频起伏 + 碎石双阈值 |
| `T_ENV_Rock` | 石头 | 大块噪声 + 细噪 |
| `T_ENV_Wood` | 围栏 | 竖向木纹（正弦 × 噪声调制） |
| `T_ENV_Bark` | 树 | 竖向深纹 + 斑块 |
| `T_ENV_Metal` | 油桶 | 拉丝 + 锈斑（低频噪声阈值） |

**材质**
- 6 个环境材质挂 `_BaseMap` 并设置平铺（路 6×6 / 草 8×8 / 木 3×1 / 金属 2×1 / 石与树皮 2×2）。
- 新建 `MAT_ENV_Ground`（草地 8×8），替换 SCN_Game 地面原本的**内置默认材质**。
- **踩坑并修正**：只挂图不改底色会让颜色乘两遍（画面整体压暗，均值 125.9→96.5）；
  把带贴图材质的 `_BaseColor` 统一改成白后恢复正常（均值 113.6/132.0/125.4，偏绿符合草地）。

**守卫测试** `Game/Tests/View/ContentPipelineTests.cs`
- 每个环境材质必须有 `_BaseMap`、着色器不能丢；
- 贴图必须来自 `Assets/Art/Textures`、mipmap > 1、Repeat、导入为 Default/sRGB、不开 Read-Write；
- `_BaseColor` 必须为白（防止贴图被二次压暗）。

## 三、验收证据

| 项 | 结果 |
|---|---|
| EditMode | **1106 / 1106 / 0**（+2 内容守卫） |
| PlayMode | **90 / 90 / 0**（像素证据用例全部保持绿） |
| 画面细节量（相邻像素灰度差均值） | **0.957 → 1.493（+56%）** |
| 画面均值 | (125.9, 135.5, 144.5) → (113.6, 132.0, 125.4)，绿色通道占优 = 草地 |
| 目视 | 地面有草地斑驳、树干有树皮纹理、远景不再是纯灰平面 |

## 四、受限

- 贴图是**程序化占位**（256²），不是美术资产；分辨率与色彩层次离正式资源还有距离。
- 只覆盖**环境**：4 个角色材质仍是纯色（胶囊体在所有截图中仍是灰模）。
- 未做法线贴图/粗糙度贴图/通道打包，光照细节仍靠基础 albedo。
- 未接 Android 的 ASTC 压缩配置（当前走默认压缩）。
