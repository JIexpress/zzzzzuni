# 帧耗基线 · 跑法（给另一台机 / 游戏机）

> 目的：两台机用**同一套参数**量同一件事，数字可直接并排比。
> 核心规矩：**不要报「多少帧」**——开了垂直同步，「帧率」量的是显示器刷新率，不是成本。

## 0. 前提

- 仓库：`D:\Dev\ZFrame`（或你本地的路径），分支 `main`，**HEAD ≥ `76707f3`**（`git pull` 即可，探针已入库）
- Unity **2022.3.62f3c1**，URP **14.0.11**
- 探针文件：`UnityProject/Assets/Game/Bootstrap/FrameBaselineProbe.cs`（只在命令行带参数时启用，平时零开销）

## 1. 出包（一次）

```powershell
cd <仓库根>
powershell -NoProfile -ExecutionPolicy Bypass -File Tools/build_player.ps1
```

产物：`Build/Windows64/ZFrame.exe`。构建会自动把版本号写回 `Tools/version.json`，正常现象。

## 2. 跑基线（两套口径，各 5 轮）

**成本口径（用来比性能）**：

```powershell
cd Build\Windows64
.\ZFrame.exe -framebaseline-vsync0 -screen-width 1920 -screen-height 1080 -screen-fullscreen 0
```

**实机口径（用来比体验）**：

```powershell
.\ZFrame.exe -framebaseline -screen-width 1920 -screen-height 1080 -screen-fullscreen 0
```

每轮约 **10 秒**自动退出，在 `Tools/Probes/out/` 生成 `frame-baseline-<UTC>.json`。

**跑的时候守三条**：

1. **插电**，电源方案设「高性能」（省电模式会压 iGPU 频率）；
2. **窗口保持焦点**，别切出去（失焦会限帧，JSON 里 `focused=false` 会露馅）；
3. **别同时开采集工具**（我实测：并发轮询 GPU 计数器会让 GPU p50 从 3.12 漂到 3.37，+7.4%）。

## 3. 怎么读 JSON

关键字段（`statistics` 下每项都有 p50/p95/p99/mean/max）：

| 字段 | 含义 | 拿它干什么 |
|---|---|---|
| `gpuFrameTime` | GPU 每帧耗时 | **主判据**，加内容后看它涨多少 |
| `cpuMainThreadFrameTime` | 主线程 | 看逻辑/提交有没有爆 |
| `cpuRenderThreadFrameTime` | 渲染线程 | 看 draw call 提交压力 |
| `setPassCalls` / `batches` / `triangles` | 渲染经济性 | 加内容时看有没有失控 |
| `cpuFrameTime`（asShipped 口径） | 帧间隔 | **只说明有没有被 vsync 钳住，不是成本** |

## 4. 怎么比（重要）

- **取 5 轮的中位数**，不要拿单轮比单轮；
- 差值要超过**实测包络**才算真变化：GPU ≈ **10%**、主线程 ≈ **12%**、渲染线程 ≈ **20%**；
- 落在包络内就重跑，不许下结论；
- 冷启第一轮会偏低（PSO 编译方向，未取证），**第一轮先丢掉**。

## 5. 本机参考值（引擎机，780M/RDNA3，2026-11-15）

| 指标 | cost 口径（vSync 0） | asShipped（90Hz vSync） |
|---|---|---|
| GPU p50 | **3.12 ms** | 3.58 ms |
| 主线程 p50 | 3.61 ms | 2.97 ms |
| 渲染线程 p50 | 0.75 ms | 0.97 ms |
| 帧间隔 p50 | ≈3.6 ms | **11.11 ms（钳制值）** |
| SetPass / Batches | 28 / 84 | 同 |
| Triangles / Vertices | 106,782 / 97,051 | 同 |

质量档 **Medium（index 1）**、MSAA **2**、renderScale **1**——**不要为了数字好看降档**，要比就比同一档。

## 6. 把结果发回来

把 cost 口径的 5 份 JSON（文件名带时间戳）打包发回，或在你的仓库里 `git add Tools/Probes/out/frame-baseline-*.json` 提交。我这边并排出一张两机对照表，写进 `Docs/Planning/帧耗基线-2026-11-15.md`。
