# 技术前瞻路线图 —— 三大新方向（2026-11-04 立项）

> 定位：**游戏本体后置，先技术储备**。每个方向走"最小验证切片 → 评估 → 全量投入"三段式。
> 所有任务遵守 AGENTS.md 治理规则（施工/验收分离、落盘交接）。参考知识库：`.agents/skills/gamedev-course/references/k03-advanced-systems.md`（GOAP/效用AI/行为树）、`k04-engine-internals.md`（大世界/浮点/LOD/SRP）——子代理按需查阅。

## 方向一：AI 自主 NPC / AI 队友（"不是按预设跑，是自己找事做"）

**技术选型**：效用 AI（Utility AI）+ GOAP 混合。行为树只会"按条件分支"，做不到自主目标选择。
**切片目标（A-TECH-01）**：3 个 NPC 在场景里自主决策——系统提供"可能的行动+代价/收益评估函数"，NPC 根据自身状态与世界状态**自己排序选择**（如：疲劳→去休息；发现掉落物→去捡；玩家靠近→跟随或战斗）。
**验收口径**：EditMode 用例——同一世界状态输入下效用排序正确；改变状态后选择改变（自主性证据）；PlayMode 观察三个 NPC 行为分化（同起点不同行为路径）。
**全量投入的前提**：切片通过 + 目标驱动规划（GOAP plan）原型可行。

## 方向二：玩家装配系统（坎巴拉/旷野之息式）

**技术选型**：Unity 物理关节（ConfigurableJoint）+ 连接点（AttachmentPoint）系统 + 手持/抓取交互（复用 InteractSystem）。
**切片目标（A-TECH-02）**：场景里 3 种零件（方块/推进器/轮子）+ 连接点标记——玩家抓取零件靠近另一个零件的连接点→吸附预览（高亮）→释放后 ConfigurableJoint 连接成复合体→推进器点火（施加力）→复合体在物理下运动。零预制装配（全运行时构建）。
**验收口径**：PlayMode——两零件连接后成为单一物理体（joint 断开即分离）；推进器力生效（位移证据）；零件可拆重装。
**全量投入的前提**：切片稳定（不抖动不爆炸）+ 装配图数据结构（模块化载具的拓扑）原型。

## 方向三：行星尺度无缝世界（飞出大气层/重力变化/贴图↔建模无缝）

**技术选型**：三段难题拆解——
1. **浮点精度**：远离原点 >10km 抖动 → 浮点原点重定位（floating origin：相机偏移超阈值时全场景平移回原点）
2. **尺度过渡**：地表细节 → 高空地形块 LOD → 太空球体（"贴图↔建模无缝切换"= LOD 链+浮点尺度下的单位制）
3. **重力系统**：球面重力（指向行星中心）替代平面重力，轨道速度概念验证
**切片目标（B-TECH-03，原生 C++/窗口程序做——无 Unity 依赖，直接在 zrender 窗口程序验证数学与渲染）**：①浮点原点重定位演示：相机从原点飞到 100,000m 外再飞回，验证浮点累积误差被重定位消除（顶点抖动前后对比截图）②球面行星渲染雏形（半径 6.371e6 m 的球+简单高度着色，near/far 相机或对数深度）③球面重力下的抛物线轨迹可视化。
**验收口径**：窗口程序 `--planet` 模式：100km 外无抖动（截图像素对比）+ 球面行星渲染 + 轨迹线符合球面重力预期（数值断言）。
**全量投入的前提**：切片通过 + 与 Unity 侧集成方案设计（这是 Unity/自研双管线共享的世界组件）。
