# ZFrame 试玩指南

> 这是一个**技术演示**，不是完整游戏。你能在里面走动、跟场景里的东西互动、看画面效果。
> 没有剧情、没有目标、没有声音。做它主要是为了验证一套自研渲染管线和玩法框架能不能跑通。

---

## 一、装之前

**需要**：
- Windows 10 或 11，64 位
- 独立显卡或较新的核显（这台开发机是 AMD Radeon 780M 核显，能跑）
- 约 100 MB 磁盘空间
- 不需要联网

**安装包**：`ZFrame-Setup-0.1.0.32.exe`（24 MB）

---

## 二、安装时会遇到拦截（重要）

这个包**没有代码签名证书**，Windows 会拦你两次：

**第一次：SmartScreen 蓝屏提示**

> "Windows 已保护你的电脑"

点 **「更多信息」** → 再点 **「仍要运行」**。

**第二次：用户账户控制（UAC）**

点 **「是」**。

为什么没有签名：代码签名证书一年几千块，这个演示不值当。签名的作用是让 Windows 知道"这个 exe 是谁做的、没被篡改过"，不带签名不代表有病毒，但**你确实应该只运行你信任来源的文件**。

如果这两步让你不放心，可以不用安装包，直接跑免安装版（见第四节）。

---

## 三、怎么玩

装完从**开始菜单**找 ZFrame 启动（没有桌面快捷方式）。会先过一个启动画面，然后进主场景。

| 操作 | 键 |
|---|---|
| 移动 | **W A S D** |
| 互动（捡东西 / 触发） | **E** |
| 暂停 | **Esc** |
| 撤销上一步拾取 | **Ctrl + Z** |

**手柄也支持**：左摇杆移动、A 键（南键）互动、Start 暂停。

进去之后能做的事：
- 在场景里走动
- 靠近可交互物按 E
- 按 Esc 开暂停菜单：继续 / 设置（画质、音量在这里）/ 退出到菜单
- 捡错了按 Ctrl+Z 撤回

---

## 四、免安装玩法

如果你不想装，`Build/Windows64/` 整个文件夹拷走，双击 `ZFrame.exe` 就能跑。
这个包不需要安装、不写注册表，删文件夹就是卸载。

---

## 五、已知的限制

这些不是 bug，是还没做：

| 限制 | 说明 |
|---|---|
| **没有声音** | 音频系统接好了，但没有配 BGM 和音效资产 |
| **只有一个场景** | 没有关卡流程，进去就是那一个场景 |
| **没有存档目标** | 存档系统在，但没有"进度"这个概念可存 |
| **没有剧情/任务** | 纯技术演示 |
| 帧率 | 核显（Radeon 780M）上能流畅跑；具体帧率随场景和分辨率变化，未做完整基准 |

可能遇到的真实问题：

- **启动黑屏几秒**：在编译着色器，第一次启动慢，之后快
- **切窗口后卡一下**：正常，在重建交换链
- 如果启动失败，程序会弹一个错误提示框，把上面的文字发给我

---

## 六、卸载

设置 → 应用 → 找到 ZFrame → 卸载（开始菜单里也有卸载项）。
或者直接删安装目录（默认在 `C:\Program Files\ZFrame`）。

---

## 七、这是什么做的

- Unity 2022.3 LTS
- 自研渲染内核（C++ / D3D12，通过 P/Invoke 接进 Unity）
- 双后端：D3D12 和 Vulkan，同一套接口
- 超分和帧生成用的是 AMD FidelityFX

技术细节在仓库根目录的 `README.md`，那份是给开发者看的。
