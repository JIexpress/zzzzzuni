## 0. 一句话

一个 Unity 3D 游戏**框架**（Track A，玩法层可复用）
＋ 一个自研 **C++ 渲染内核**（Track B，D3D12/Vulkan 双后端，独立可跑、已能向 Unity 出画面）。

## 3. Track B —— ZRender 渲染内核

### 3.1 DataKernel（数据内核）

`zkernel`（C++）+ `ZKernelNative` / `ZKernelWorld` / `ZkEntity` / `ZkMask` / `ZkEachCursor` / `ZkEachBatchHandler`（C#）

- **128 位掩码**（`ZkMask`）组件筛选
- **SoA + chunk** 布局；`Compact` 收缩
- 查询：单次遍历 + 游标迭代（`ZkEachCursor`）+ 批量回调（`ZkEachBatchHandler`）
- **并行 Each**（工作分块，`EachParallel`）
- **架构型迁移**（Add/RemoveComponent 搬行，实测 **28M 行/s**）
- C ABI（12 个 `ZK_*` 导出）+ C# 绑定；`ZkWorldStats`

### 3.2 RHI（硬件抽象层，按 Vulkan 语义设计）

`zrhi_types` / `zrhi_handles` / `zrhi_barriers` / `zrhi_device` + `d3d12/` + `vulkan/`

- **双后端**：D3D12（主）/ Vulkan（第二，全特性镜像）
- 资源：Buffer/Texture/Sampler/PSO/DescriptorSet
- **Bindless**（D3D12 描述符堆 / Vulkan update-after-bind）
- **屏障模型**：资源状态跟踪、批量提交、**split barrier**、批次截断可观测（>128 条丢弃会累计计数并告警）
- **GPU 时间戳**（每 pass）
- 交换链重建状态机（尺寸裁决/台账/粘性清除与回粘）
- 设备统计 `ZrDeviceStats`：别名堆/图像/缓冲计数 + Present 失败 + 描述符分配失败 + 屏障截断

### 3.3 RenderGraph

`rg_render_graph`

- 声明式加 pass；**自动推导依赖边**
- **资源生命周期 + 别名复用**（同帧不同生命周期的纹理共用内存）
- **屏障合并**（按依赖批量插）
- pass 顺序编译；`Present` 作为终节点
- 导出：`rg_export`（JSON/文本，含 passes/edges/barriers/alias）

### 3.4 资产与提交

`zmesh` / `draw_list`

- `.zmesh`：Mesh → SoA 烘焙（interleaved 32B/vertex），双侧（C++ 写 / C# 读 `ZMesh`/`ZMeshBaker`）
- 共享可见性 + **64 位 sort key** + radix 排序
- **状态聚类合批**（draw list items→batches）

### 3.5 光照与阴影

`cluster_lighting` / `shadows` / `ssr_pass` / `gi_probes`

- **簇光源**（分簇分配、不重叠/边界/覆盖测试）
- **CSM 级联阴影** + texel snap 稳定 + 逐光阴影图
- **SSR**（mip 链 + 模糊核）
- **动态 GI 近似**（探针三线性/辐照度/轮转）
- **NPR 描边**；PBR 前向
- **对等闸门**：同场景 URP vs ZRender 视觉对等 + 帧耗不劣（有报告落盘）

### 3.6 超分

`zupscaler`：`upscaler_chain` / `upscaler_caps` / `fsr_upscaler` / `bilinear_upscaler` / `dlss_upscaler`

- **UpscalerChain** 能力矩阵选优
- **FSR 4.1**（AMD 主路径，本机 780M 实测）/ **FSR 3.1**（非 AMD 回退）
- **DLSS** 骨架（Streamline，无 NVIDIA 硬件未验证）
- 双线性保底；设置页可切（`UpscalerSettingOptions`）

### 3.7 帧生成

`fg_ffx`

- **FFX Frame Generation 3.1.6** 集成（原生完成）
- Unity 侧走 **dxgi.dll 代理 + 双交换链接管**，真插帧（60 真帧 → 120 呈现）
- 每帧提交 depth/MV；MSAA 告知与恢复；采集常驻
- 安装竞态守卫 + 非 D3D12 门控（修过阻断级启动崩溃）

### 3.8 GPU 工具链

`gpu_hud` / `renderdoc_capture` / `rg_export` / `devconsole_proto`

- **HUD 统计聚合**（DrawCall/字节估算/滑窗峰值/JSON）
- **RenderDoc 应用内挂接**（官方 app API；未挂接时明确报错 `renderdoc_not_attached`，不静默）
- **RG 导出**（见 3.3）
- **原生 DevConsole 协议**（白名单/信封转义；`--devconsole` 绑 127.0.0.1）
- 自动跑分回归：`bench_regression.ps1` + `bench_baseline.json`（7 项指标，可 `BENCH_GATE=1` 强制）

### 3.9 与 Unity 的集成现状（重要）

| 项 | 状态 |
|---|---|
| 原生接受 Unity 的 `ID3D12Device` | ✅ `CreateFrom(external)` |
| 渲染到共享纹理 → Unity 采样 | ✅ 深蓝背景 + 三 cube 已出现在 Unity 窗口，**颜色变异证伪过** |
| 替代 URP 渲染游戏场景 | ❌ **没有 `DrawRenderers`**，游戏 3D 内容不会画；相机矩阵也不读 Unity |
| 门控 | ✅ 仅 D3D12 启用；D3D11 明确回退 URP |

**当前是"演示级集成"**：ZRender 画 3D 背景，Unity 画 UI。再往前需要搬 Unity 的可见物件/相机/材质/光照。

## 8. 已知缺口（诚实清单）

### 影响"可玩"的
1. **ZRender 只画演示内容**：无 `DrawRenderers`/`DrawSkybox`，游戏 3D 内容不画；相机矩阵不读 Unity；只处理 `cameras[0]`
2. **每帧 `WaitIdle`**：CPU/GPU 串行化，接真实场景前要换 fence 双缓冲
3. **共享纹理回读只有 1/8 行正确**：潜在布局缺陷（Unity 走 SRV 采样暂不受影响）
4. **纹理重建未 Destroy 旧对象**：改分辨率时每次漏一个
5. **Windows 切 D3D12 后 A 轨像素用例未补跑**

### 影响"交付"的
6. **无安装包**：只有目录形式 exe（83MB）
7. **构建报告体积口径错**：报整个 `Build/`（385MB）而非 `Windows64`（83MB）
8. **CI 只覆盖原生**：916+48 个 Unity 用例全靠本地
9. **PSO 磁盘缓存缺失**：首次加载/切场景着色器编译卡顿
10. **Metal 后端缺失**：macOS 无法运行（无硬件，方案已声明不承诺）

### 质量隐患
11. 原生 DevConsole 无客户端认证；`rg.export` 路径未限定目录（本机任意写）
12. `gpu_hud.h` 文档写 `ceil(w/2^m)`，实现是下取整
13. RG 导出对 Imported 资源把 depth 写成 `RGBA8Unorm 1×1`（真实 `D32Float 640×480`），排查黑屏会误导
14. 游戏内容简陋（角色/关卡/手感），**按要求未投入**
